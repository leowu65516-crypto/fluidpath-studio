## 模块状态

- 故障码模块：已支持图纸内自定义故障码、双语名称、信号阈值/保持时间、滞回、元件/管路高亮组、步骤化排查线索和 Markdown 诊断报告；模块配置格式为 profile `0.2-draft`。
- 工况验收：状态独立为 `PASS`、`FAIL`、`INVALID`、`UNKNOWN`、`NOT_RUN`。结果绑定图纸 ID、Schema、应用版本、引擎版本和规则版本。停流-only 案例即使断言通过，也会标记为 `partial`，不能证明整机全部正确。
- 状态分层：`displayDisabled` 只影响画布淡化；`disabled` 是工程禁用；`teachingOverride`/旧 `forceFlow`/`forceStop` 只影响教学显示；图层隐藏、故障高亮和动画暂停不改变工程验收结果。工程禁用一条旁支只切断该支路：停流传播在分支接头（三通/四通）处停止，不会把同一接头上的其他支路一起判停。
- 工况与演示：工况保存所有已存在元器件/管路的可编辑属性、介质、工程/教学显示状态和画布显示设置，但不回滚对象增删或端口连接；自定义演示每一步可引用一个完整工况，并支持命名、增删、替换、重排与重复步骤。GIF 可选择单一工况或整段演示：整段演示按步骤恢复完整状态导出，支持逐步停留和步骤间切换时长，且不输出步骤高亮。
- 介质检查：当前输出声明、定性多来源混合或未知；不会在缺少参数时伪造精确温度、压力、流量、比例或蒸汽干度。
- 桌面关闭：确认退出后主进程忽略渲染层 `beforeunload`，关闭最后一个窗口即退出；不再出现窗口消失但进程驻留、只能强制退出的情况。
- 停流归因：按「本管→上游供液→下游去处」分层；汇流点先判断是否仍有来液，避免把关闭的旁支阀误报成主路根因；多条来路都断时汇总所有阻断点。
- 线路编号 Linter：回路诊断检测「管路 N / Pipe N」自动编号重复；一键重排只改自动编号，自定义名称保留。
- 智能绘图：工具栏/空画布入口的三步向导，7 个咖啡机液路模板（水路/咖啡/即热/奶路/蒸汽/组合/双锅炉 BCMTS-lite）；咖啡模板可选单锅炉蒸汽杆；奶出口带三通排废，蒸汽/奶路补水带电磁阀，full 使用共用供水网 + 流量计 + 排废总阀，支持自由描述、空画布加载/非空追加、预览、结构检查、一次撤销；生成后右栏「继续完善」可加功能块、选接点、加关键词、自动布线。保存状态区分本机草稿与文件保存，首次修改/插入/导出/关闭均有对应提示。模板默认待机并带推荐工况；新增泵出口单向阀、锅炉压力表/OPV/安全阀等安全附件与工程检查（安全阀、压力表、单向阀、泵死堵、蒸汽注入奶路、奶路清洗、默认状态、待机工况），预览/继续完善面板可展开定位。自由文本命中后自动推进配置步骤，支持元件级词（压力表/单向阀/三通/锅炉/水泵）；奶路清洗按拓扑判定；安全阀/OPV 常闭，泄压管默认停流；压力表死端显示“传压不流过”；新增/连管后 error 数上升会立即 toast；本机 localStorage 计数模板/意图/功能块/保存/工程点击/工况切换，不联网。模板卡改为紧凑骨架预览，插入后默认聚焦主链，可切换“只看主链/显示全部”，full/dual 显示供水/咖啡/蒸汽奶路/排废四分区。主链折叠基于模板节点的 smartSecondary 标记（语言无关），串联单向阀/流量计保留；模板卡显示完整模板投影（二级系统/附件降透明度、不删减），插入后默认完整图纸并聚焦主链；主链视图仍可手动切换，缩略图与画布元器件集合一致；所有模板默认走线 0 交叉、元件 0 重叠，并有回归测试守护；模板坐标按真机参考图扩展到 1.65 倍间距（最近中心距约 181px，参考图约 176px），插入图更疏朗。
- 阀件库：除常规两通/三通电磁阀外，新增两通隔膜阀，以及三口两位隔膜切换阀；后者固定三个双向端口、两个工程有效状态。两条通路都经过用户选择的公共端口，因此可表示 `P1↔P2 / P1↔P3`、`P2↔P1 / P2↔P3` 或 `P3↔P1 / P3↔P2`，未选支路会停流。脉冲空气阀支持开/关状态（属性面板、画布徽标、工况快照、故障模拟），它只控制空气支路；工程禁用或关闭不会切断并联的液体主路。

## 已知限制

- 受限 AI 操作不支持任意字段写入、完整 v4 `unresolved/evidence` 语义、跨图复制和 CFD/精确混合求解；声明介质不会自动变成已解析工程介质。
- 智能绘图的机型差异目前覆盖单锅炉、单锅炉带蒸汽杆、双锅炉、双锅炉 BCMTS-lite、即热/热块；HX、奶路文氏/双泵、清洗回罐变体尚未模板化。自由文本限于咖啡机液路领域，不接外部模型。
- 端口方向会用于连接校验，但阀、三通和无单向阀管路仍可能存在双向或工况相关流向，不能仅凭图纸静态方向断言真实物理流向。
- 没有正向流动断言的验收案例只能证明声明的停流断言，不代表整机工况完全正确。
- 大图性能仍需在生产构建和真实桌面环境继续采样后再决定是否做更深的几何拆分或虚拟化。
