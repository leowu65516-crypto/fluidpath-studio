## 模块状态

- 故障码模块：已支持图纸内自定义故障码、双语名称、信号阈值/保持时间、滞回、元件/管路高亮组、步骤化排查线索和 Markdown 诊断报告；模块配置格式为 profile `0.2-draft`。
- 工况验收：状态独立为 `PASS`、`FAIL`、`INVALID`、`UNKNOWN`、`NOT_RUN`。结果绑定图纸 ID、Schema、应用版本、引擎版本和规则版本。停流-only 案例即使断言通过，也会标记为 `partial`，不能证明整机全部正确。
- 状态分层：`displayDisabled` 只影响画布淡化；`disabled` 是工程禁用；`teachingOverride`/旧 `forceFlow`/`forceStop` 只影响教学显示；图层隐藏、故障高亮和动画暂停不改变工程验收结果。
- 工况与演示：工况保存所有已存在元器件/管路的可编辑属性、介质、工程/教学显示状态和画布显示设置，但不回滚对象增删或端口连接；自定义演示每一步可引用一个完整工况，并支持命名、增删、替换、重排与重复步骤。GIF 可选择单一工况或整段演示：整段演示按步骤恢复完整状态导出，支持逐步停留和步骤间切换时长，且不输出步骤高亮。
- 介质检查：当前输出声明、定性多来源混合或未知；不会在缺少参数时伪造精确温度、压力、流量、比例或蒸汽干度。
- 阀件库：除常规两通/三通电磁阀外，新增两通隔膜阀，以及三口两位隔膜切换阀；后者固定三个双向端口、两个工程有效状态。两条通路都经过用户选择的公共端口，因此可表示 `P1↔P2 / P1↔P3`、`P2↔P1 / P2↔P3` 或 `P3↔P1 / P3↔P2`，未选支路会停流。
- CI：GitHub Actions 在 push/PR 执行 `npm ci` 与 `npm run check`。

## 已知限制

- 受限 AI 操作不支持任意字段写入、完整 v4 `unresolved/evidence` 语义、跨图复制和 CFD/精确混合求解；声明介质不会自动变成已解析工程介质。
- 端口方向会用于连接校验，但阀、三通和无单向阀管路仍可能存在双向或工况相关流向，不能仅凭图纸静态方向断言真实物理流向。
- 没有正向流动断言的验收案例只能证明声明的停流断言，不代表整机工况完全正确。
- 大图性能仍需在生产构建和真实桌面环境继续采样后再决定是否做更深的几何拆分或虚拟化。
